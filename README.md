# Function Hall Booking Application

A front-end demo for a function hall booking platform.

## Features
- Function hall availability
- Hall selection
- Booking date and event type
- Guest count validation
- Chair selection and pricing
- Decoration packages
- Automatic total calculation
- Demo payment options: UPI, Card, Net Banking
- Booking confirmation with booking ID
- Responsive design

## Run
Open `index.html` in a browser.

## Important
The payment flow is a DEMO only. It does not process real payments or store bookings in a server/database.
